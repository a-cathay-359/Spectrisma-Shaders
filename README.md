# 🌈 Spectrisma Shaders (SS)

**Spectrisma** is a modular, performance-first shaderpack designed for Minecraft. Whether you are playing on a high-end PC or a potato laptop from the school computer lab, Spectrisma delivers the perfect balance of visual aesthetics and extreme performance.

**Spectrisma** 是一款专为追求**极致性能**与**高级色彩美学**而打造的模块化 Minecraft 光影包。无论你是顶配 RTX 玩家，还是正在使用学校机房“古董机”的核显党，SS 都能为你提供最完美的画质与帧数平衡。

---

## ✨ Key Features / 核心特性

*   🚀 **Layered Performance Presets / 分层性能预设**
    From "Germinated Potato" (absolute maximum FPS) to "High" (stunning visual quality). One shader, infinite possibilities.
    从“发芽的马铃薯”（极限帧数）到“高配”（极致画质），一套源码，满足所有硬件需求。
*   🎨 **6 Advanced Color Grading Filters / 6 套高级调色滤镜**
    Includes None, Vivid, Realistic Neutral, Cold, Warm, and Anime style. Fine-tune with built-in exposure, saturation, and contrast sliders!
    包含无滤镜、原版明艳、真实中性、真实冷调、真实暖调以及日漫风。支持曝光、饱和度、对比度实时滑块微调！
*   🛡️ **Multiplayer & Server Safe / 绝对服务器安全**
    Pure visual rendering. We NEVER modify server logic, intercept network packets, or control entity culling. 100% safe for any anti-cheat environment.
    纯视觉渲染。绝不修改服务器逻辑、不拦截网络包、不强制实体剔除。在任何带有反作弊的多人服务器中100%安全！
*   🔮 **Future-Ready / 面向未来**
    Supports upcoming software ray-tracing (RT) modules (coming soon as a standalone paid package).
    底层架构已为未来的软件光追（RT）独立模块预留接口。

## 🥔 Preset Overview / 预设档位总览

*   **Germinated Potato / 发芽的马铃薯**: Ultimate performance for integrated graphics. Water becomes pure colored glass, clouds and stars are removed. (Max FPS!)
    *极致性能，核显战神。水变纯色玻璃，云层星空剔除，专为多人对战和低配机打造。*
*   **Potato / 马铃薯**: Simulates vanilla rendering with an extra high-quality color grading filter. Perfect for players who don't want to lose vanilla mechanics.
    *模拟原版渲染，仅叠加高级色彩滤镜。保留原版水波和云层，原汁原味。*
*   **Low / 低配**: Basic PCF shadows for entry-level graphics. 
    *基础 PCF 阴影，入门级核显/独显的甜点位。*
*   **Medium / 中配**: Adds SSR (Screen Space Reflections), SSAO, and God Rays.
    *加入屏幕空间反射、环境光遮蔽和体积光，入门独显体验区。*
*   **High / 高配**: Full-resolution volumetric clouds, PCSS soft shadows, PBR, and meteor shower easter eggs!
    *全分辨率体积云、PCSS软阴影、PBR材质及流星雨彩蛋。画质拉满，专为高端显卡准备。*

## 📥 Installation / 安装指南

1. Install **Minecraft 1.21.11** and **Iris Shaders**. (Requires Java 21)
2. Download the `.zip` file and place it into your `shaderpacks` folder.
3. Select **Spectrisma** in the game's shader menu.
4. Go to **Shader Options** to tweak your performance preset and color filters!

**🇨🇳 中文安装指南 / Chinese Installation Guide:**

1. 安装 **Minecraft 1.21.11** 及 **Iris 光影加载器**（需要 Java 21）。
2. 将下载的 `.zip` 压缩包直接放入 `.minecraft/shaderpacks` 文件夹。
3. 在游戏内的光影菜单中选择 **Spectrisma** 应用。
4. 点击 **光影设置**，自由切换你的性能预设和色彩滤镜！
